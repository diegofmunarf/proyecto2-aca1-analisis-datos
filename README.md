# proyecto2-aca1-analisis-datos
Descripción

Este proyecto desarrolla un proceso de caracterización, auditoría de calidad, análisis descriptivo y preparación de una base de datos de comunicaciones administrativas correspondientes al año 2025.

Objetivo

Examinar la estructura y calidad de la información, identificar posibles inconsistencias y realizar transformaciones que permitan disponer de una base preparada para posteriores procesos de análisis.

Herramientas utilizadas

Python.

Google Colab.

Pandas.

CODAP.

GitHub.

Estructura del repositorio

notebooks/: código y desarrollo del análisis en Google Colab.

resultados/: gráficos y resultados del análisis exploratorio.

documentos/: informe académico y documentos de la ACA 1.

Características de la base de datos

Registros: 33.842.

Variables originales: 15.

Variables de la base auditada: 16.

Periodo de referencia: año 2025.

Proceso desarrollado

Carga y caracterización inicial de la información.

Auditoría de calidad de los datos.

Identificación de valores faltantes y posibles inconsistencias.

Análisis descriptivo de variables.

Revisión de comportamientos temporales.

Aplicación de transformaciones ETL.

Exportación de la base auditada.

Reproducibilidad

El notebook contiene los procedimientos desarrollados para realizar la auditoría y preparación de los datos. Para reproducir el análisis se requiere disponer de una copia autorizada y debidamente anonimizada de la base de datos de entrada.

Protección de datos

Por motivos de confidencialidad, este repositorio no publica la base original ni archivos que contengan nombres o identificaciones personales.

Versión

Primera versión – ACA 1.
